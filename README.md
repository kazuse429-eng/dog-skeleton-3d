# 犬の骨格・臓器 3D

**▶ 開く: https://kazuse429-eng.github.io/dog-skeleton-3d/** （スマホでも使えます）

中型犬（体高 約38cm）の全身骨格を、ブラウザでぐるぐる回して見られるビューアです。
左の一覧から **骨の名前で選ぶ** と、その骨が色付きで強調され、カメラが寄ります。

- 和名・ラテン名で検索（例: `上腕骨`, `femur`, `胸椎`）
- グループごとの選択（例: 「胸椎（13個）」を選ぶと13個まとめて強調）
- 3D 上の骨をクリックしても選べる（マウスを乗せると名前が出る）
- 表示の切り替え: 周りを薄く ／ 選んだ骨だけ ／ 全部そのまま
- URL の `#sel=humerus` で選んだ状態を共有できる

## 勉強用の機能

- **🎯 クイズ**
  - 「これは何？」… 光った骨・臓器の名前を4択で答える（1〜4キーでも選べる）
  - 「どこ？」… 出された名前の骨・臓器を3Dでクリックする（2回外すと正解の場所を表示）
  - 範囲（骨：前肢、臓器：消化器 など）、和名／ラテン名、問題数（10・20・全部）を選べる
  - 結果画面から「間違えたものだけもう一度」
- **苦手の記録** … 答えた結果をブラウザに保存し、苦手・まだのものから優先して出題。一覧の名前の横に印（赤＝苦手、黄＝練習中、緑＝覚えた）
- **🏷 名前** … 3D の上に名前を表示。何も選んでいないときは「胸椎（13個）」のようにグループでまとめ、グループを選ぶと1個ずつ表示

記録はこの端末のブラウザの中だけに保存され、どこにも送信されません（設定の「記録を消す」で消去）。

## 臓器モード

上のボタンで **骨格 ／ 臓器 ／ 両方** を切り替えられます。「両方」では骨が半透明になり、体の中の臓器の位置が分かります。

| 器官系 | 臓器 |
|---|---|
| 神経系 | 大脳、小脳、脳幹、脊髄 |
| 呼吸器 | 喉頭、気管、左肺（前葉・後葉）、右肺（前葉・中葉・後葉・副葉） |
| 循環器 | 心臓、大動脈、後大静脈 |
| 消化器 | 食道、胃、十二指腸、空腸、回腸、盲腸、結腸、直腸、肝臓、胆嚢、膵臓 |
| 造血・リンパ系 | 脾臓 |
| 泌尿器 | 左右の腎臓・尿管、膀胱 |
| 内分泌 | 甲状腺、左右の副腎 |
| 生殖器（雄） | 前立腺、精巣 |
| その他 | 横隔膜 |

臓器の形も模式図です。位置関係（心臓は第3〜6肋骨のあいだ、右腎は左腎より前、脾臓は胃の左 など）を優先しています。

左上の「☰ 一覧」で名前の一覧を閉じて、3D を広く使えます。

## 使い方

`index.html` をブラウザで開くだけです（サーバー不要・オフラインで動きます）。
GitHub Pages で公開する場合は、このフォルダをそのままリポジトリのルートに置きます。

| 操作 | |
|---|---|
| 左ドラッグ | 回転 |
| 右ドラッグ | 平行移動 |
| ホイール | 拡大・縮小 |
| 骨をクリック | 選択 |

## 収録している骨

| 部位 | 骨 |
|---|---|
| 頭部 | 頭蓋骨、下顎骨 |
| 脊柱 | 頸椎7（環椎・軸椎を含む）、胸椎13、腰椎7、仙骨、尾椎20 |
| 胸郭 | 肋骨13対、肋軟骨13対、胸骨（胸骨柄・胸骨片・剣状突起の8個） |
| 前肢 | 肩甲骨、上腕骨、橈骨、尺骨、手根骨7、中手骨5、指骨 |
| 後肢 | 寛骨（腸骨・坐骨・恥骨）、大腿骨、膝蓋骨、腓腹筋種子骨、脛骨、腓骨、足根骨7、中足骨4、趾骨 |
| その他 | 陰茎骨（雄） |

入れていないもの: 舌骨、頭蓋を構成する個々の骨（前頭骨・頭頂骨など）、指の種子骨、鎖骨（犬では痕跡的）、後肢の第1趾（狼爪。個体により無い）。

## 精度について

形は **解剖書の模式図を立体にした程度** です。骨の個数・並び・位置関係・おおよその比率は
一般的な獣医解剖学の記載（椎式 C7 T13 L7 S3 Cd20、肋骨13対 など）に合わせていますが、
CT などから作った実物の形ではありません。学習の補助としてお使いください。

## 作り直し方（開発者向け）

骨はすべて `gen/bones.py` に距離場（SDF）として書いてあり、`gen/build.py` が骨ごとに
メッシュを取り出して間引き、`bones_data.js` に書き出します。
Blender 4.x 同梱の Python（numpy と openvdb が入っている）で動かします。

```
blender --background --python gen/build.py
blender --background --python gen/build.py -- --only skull,humerus   # 一部だけ
```

左右のある骨は左だけを作り、右はビューアで鏡像にしています。
